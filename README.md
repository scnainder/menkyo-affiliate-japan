# Menkyo Affiliate Japan 🚗

## English Version

A comprehensive affiliate marketing platform for promoting Japanese driving schools (自動車学校 - jidousha gakkou) to Japanese drivers preparing for their driver's license examination.

### Project Overview

This project focuses on:
- **Target Market**: Japanese drivers (16+ years old)
- **Target Product**: Jidousha Gakkou (Driving School) Registration
- **Goal**: Connect drivers with quality driving schools through affiliate partnerships
- **Revenue Model**: Commission-based affiliate marketing

> **Working on affiliate links?** Read [`AGENTS.md`](AGENTS.md) and [`docs/AFFILIATE_LINKS.md`](docs/AFFILIATE_LINKS.md) first.

### Key Features (Planned)

- 🎯 Affiliate Dashboard & Analytics
- 📍 School Locator (by Prefecture)
- 💰 Commission Tracking System
- 📱 Responsive Landing Pages
- 🌍 Bilingual Support (Japanese/English)
- 📊 Real-time Performance Metrics
- 🔐 Secure Payment Processing

## Japanese Version (日本語版)

日本の運転免許取得を目指すドライバーに向けた、自動車学校のアフィリエイトマーケティングプラットフォームです。

### プロジェクト概要

このプロジェクトの焦点：
- **ターゲット市場**: 日本のドライバー（16歳以上）
- **ターゲット製品**: 自動車学校への登録
- **目標**: 品質の高い自動車学校をドライバーと結ぶ
- **収益モデル**: コミッション制アフィリエイトマーケティング

### 主な機能（計画中）

- 🎯 アフィリエイトダッシュボード & 分析
- 📍 学校ロケーター（都道府県別）
- 💰 コミッション追跡システム
- 📱 レスポンシブランディングページ
- 🌍 多言語対応（日本語/英語）
- 📊 リアルタイムパフォーマンスメトリクス
